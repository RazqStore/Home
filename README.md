# متجر ديسكورد — دليل التشغيل

متجر رقمي كامل يعمل على **GitHub Pages** بدون سيرفر:
- تسجيل الدخول **بحساب ديسكورد فقط**
- الدفع يتوجه إلى **سيرفر الديسكورد** (الطلب يوصل لروم الطلبات + العميل يفتح تذكرة)
- **لوحة تحكم للمالك** (`admin.html`) تحفظ التعديلات مباشرة في المستودع
- وضع ليلي، تعدد عملات، كوبونات، مفضلة، بحث، تقييمات، متوافق مع الجوال

---

## 1) ارفع الملفات على GitHub
1. أنشئ مستودعاً جديداً (Public) مثلاً `my-store`.
2. **Add file ← Upload files** وارفع **محتوى** المجلد كله (وليس المجلد نفسه)، بحيث يكون `index.html` في جذر المستودع.
3. **Settings ← Pages ← Source: Deploy from a branch ← main / (root) ← Save**.
4. بعد دقيقة يصير رابطك: `https://USERNAME.github.io/my-store/`

## 2) أنشئ تطبيق ديسكورد (لتسجيل الدخول)
1. ادخل https://discord.com/developers/applications ← **New Application**.
2. من **OAuth2**: انسخ **Client ID**.
3. في **Redirects** أضف بالضبط:
   `https://USERNAME.github.io/my-store/auth.html` ← **Save Changes**.

## 3) عدّل ملف `config.js` (مرة واحدة)
```js
discordClientId: "الـ Client ID",
ownerDiscordIds: ["آيدي حسابك"],
```
> لمعرفة الآيدي: ادخل `admin.html` وسجّل دخول — ستظهر لك صفحة فيها الآيدي مع زر نسخ.
> أو من ديسكورد: الإعدادات ← Advanced ← Developer Mode، ثم كليك يمين على اسمك ← Copy User ID.

## 4) اربط لوحة التحكم بـ GitHub (للحفظ من اللوحة)
1. GitHub ← Settings ← Developer settings ← Personal access tokens ← **Fine-grained tokens** ← Generate.
2. Repository access: **Only select repositories** ← اختر مستودع المتجر.
3. Permissions ← Repository ← **Contents: Read and write**.
4. افتح `admin.html` ← **النشر والربط** ← الصق التوكن ← **حفظ واختبار الاتصال**.

التوكن يُحفظ في متصفحك فقط، ولا يُرفع للموقع.

## 5) اربط الطلبات بالديسكورد
في سيرفرك: إعدادات روم الطلبات ← Integrations ← Webhooks ← New Webhook ← Copy URL.
ثم في اللوحة ← **الدفع والديسكورد**: الصق الـ Webhook + رابط دعوة السيرفر ← **اختبار** ← **نشر التغييرات**.

### كيف يمشي الطلب؟
العميل يضيف للسلة ← يكتب البيانات المطلوبة (مثل الإيميل) ← «إتمام الشراء» ← يسجل دخول ديسكورد
← يُنشأ رقم طلب ويوصلك في الروم مع منشن العميل ← العميل يُوجَّه للسيرفر ويفتح تذكرة ويدفع.

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | الرئيسية (المنتجات، التصنيفات، المميزات، التقييمات) |
| `product.html` | صفحة المنتج والباقات |
| `cart.html` | السلة والكوبون وإتمام الطلب |
| `auth.html` | استقبال تسجيل الدخول من ديسكورد |
| `admin.html` | لوحة تحكم المالك |
| `data/store.json` | كل بيانات المتجر (تعدّلها اللوحة) |
| `config.js` | إعدادات الربط |
| `assets/uploads/` | الصور المرفوعة من اللوحة |

## ملاحظات
- التعديلات تظهر في الموقع بعد النشر بدقيقة تقريباً (وقت بناء GitHub Pages).
- لتجربة الموقع على جهازك افتحه عبر خادم محلي (مثلاً `python -m http.server`) وليس بالضغط المزدوج على الملف.
- رابط الـ Webhook يكون داخل ملف الموقع، فخصّص له روماً للطلبات فقط، وإذا أسيء استخدامه احذفه من ديسكورد وأنشئ واحداً جديداً.
- الخط الافتراضي **IBM Plex Sans Arabic** والأيقونات من **Lucide** — يمكنك تغيير الخط واللون من اللوحة ← إعدادات المتجر.
